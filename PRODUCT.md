# Verse

Verse is a premium native iOS eBook reader designed for people who love reading.

It combines immersive reading, thoughtful book discovery, and personal library management into a calm, elegant experience inspired by modern editorial design.

The goal is to make reading feel beautiful again.

## Core Features

- Discover books
- Build a personal library
- Read eBooks
- Track reading progress
- Organize collections
- Continue reading seamlessly

## Goals

- Premium native iOS experience
- Faithful implementation of the Figma designs
- Beautiful Liquid Glass interactions
- Smooth animations
- Portfolio-quality engineering
- Clean, scalable architecture

## Principles

- Figma is the source of truth.
- Reading comes first.
- Keep the interface calm and distraction-free.
- Prefer native iOS interactions.
- Build reusable components.
